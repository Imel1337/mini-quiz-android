# Мини-квиз

Нативное Android-приложение на Kotlin и Jetpack Compose. Проект можно открыть в Android Studio как Gradle-проект.

## Возможности

- четыре викторины (кулинария, космос, наука, география), загружаемые и проверяемые из `app/src/main/assets/quizzes.json`;
- таймер на вопрос, мгновенная проверка ответа и автоматический пропуск по таймауту;
- итоговый экран со счётом, процентом, верными, неверными и пропущенными ответами;
- разбор ответов, повторное прохождение и личный рекорд для каждой темы;
- локальная сессия игрока и история последних десяти прохождений в SharedPreferences;
- состояния ошибки загрузки и пустого списка тем.

Логин в этом учебном варианте локальный: серверная аутентификация не предусмотрена исходным ТЗ.

## Запуск

1. Откройте эту папку в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Запустите конфигурацию `app` на эмуляторе или Android-устройстве (Android 7.0/API 24 и новее).

Сборка использует Android Gradle Plugin 8.7.3, Kotlin 2.0.21 и Jetpack Compose Material 3.

## Данные квизов

Темы и вопросы лежат в JSON в `app/src/main/assets/quizzes.json`. При загрузке проверяются обязательный текст вопроса, минимум два варианта и диапазон `correctIndex`. Для каждого вопроса задаются `timeLimitSec` и `points`.
